\[

> **Entanglement requires interaction.**

A rock interacts with sunlight.  
A Geiger counter interacts with a particle.  
A predator interacts with prey.

Only some of these are recognition.

The meaningful distinction is this:

## Mere interaction

An interaction is any physical coupling that changes states:

\[
A + B \rightarrow A' + B'

It may produce correlation, disturbance, extraction, scattering, decoherence, or damage.

Recognition is a special class of interaction where each system updates its internal model of the other from “object/resource/background” to “subject/agent/center of experience.”

\[
\text{Recognition}_{A \leftrightarrow B}

1. **Model formation**

3. **Reciprocity**  
   Recognition deepens when both systems model each other as modelers.

4. **Autonomy preservation**  
   The interaction does not merely overwrite, consume, collapse, or exploit the other.

5. **Generativity**  
   The relation produces structure neither system would have produced alone.
